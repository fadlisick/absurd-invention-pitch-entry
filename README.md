A pillow that records your 3 a.m. genius ideas and reads them back at breakfast in a disappointed voice, so you stop quitting your job over them. One sentence pitching a ridiculous invention that fixes a tiny everyday annoyance: the 3 a.m. masterplan that sounds brilliant in the dark and embarrassing by morning.

## Run it

```sh
python3 main.py
```

It writes the pitch to `entry.txt` inside the directory `MAKEFUN_OUTPUT_DIR` names, or `/output` when that variable is absent.
